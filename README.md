# 🥋 Jiu-Jítsu Hub

**Uma plataforma dedicada ao jiu-jítsu, reunindo informações sobre o esporte, artigos e conteúdos de aprendizagem em um só lugar.**

O Jiu-Jítsu Hub é um projeto de desenvolvimento web que busca aproximar praticantes e interessados no jiu-jítsu por meio de uma interface intuitiva, conteúdos informativos e uma área dedicada a videoaulas.

O projeto está sendo desenvolvido com **Nextjs, Spring Boot e PostgreSQL**, com foco na construção de uma aplicação web organizada, responsiva e segura.

> **Status:** Em desenvolvimento 🚧

## 🎯 Objetivos

- Desenvolver uma plataforma web com interface responsiva.
- Apresentar informações sobre o jiu-jítsu e a prática do esporte.
- Disponibilizar artigos e materiais informativos.
- Criar uma área de videoaulas com acesso restrito a usuários autenticados.
- Aplicar boas práticas de desenvolvimento frontend e backend.

## 🚀 Como executar o projeto

As instruções de instalação serão adicionadas conforme a estrutura e as dependências forem configuradas.

### Pré-requisitos previstos

- Node.js e npm
- Java JDK
- Maven
- PostgreSQL
- Git

### Instalação

1. Clone o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Entre no diretório do projeto:

   ```bash
   cd jiujitsu-hub
   ```

3. Consulte as instruções específicas do frontend e do backend, que serão documentadas à medida que forem implementados.

> Os comandos definitivos de instalação e execução serão documentados após a configuração inicial da aplicação.
